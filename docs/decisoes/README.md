# Registro de decisões

Use esta pasta para decisões que afetam escopo, regras de negócio, arquitetura, dados, segurança ou integração, especialmente quando a equipe escolher entre alternativas.

Copie `DECISAO-template.md` para cada decisão relevante, atribua um identificador (`DEC-001`, `DEC-002`...) e registre data e estado. Não é necessário registrar toda escolha pequena de implementação.

## Exemplo (fictício)

`DEC-001 — Importação inicial de materiais` pode registrar a decisão hipotética de começar com importação de CSV preparado pela equipe, em vez de integrar imediatamente com um sistema externo. O registro explicaria o motivo, os riscos, as consequências para o escopo e a condição que faria a equipe rever a escolha. Veja o arquivo `DECISAO-template.md` preenchido como exemplo.
