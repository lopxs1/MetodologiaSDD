# Artefato — Requisitos do Sistema

Esta pasta armazena a especificação de Requisitos de Software da solução.

## Alinhamento com o Trabalho de Graduação (TG — Fatec ADS)

A especificação clara dos requisitos é a base para a modelagem dos Casos de Uso (Capítulo 2.5), para a definição do escopo no `README.md` e para a formulação dos critérios de avaliação e aceite do projeto.

## Conteúdo desta Pasta
