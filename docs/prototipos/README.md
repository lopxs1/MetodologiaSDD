# Artefato — Prototipação de Interfaces

Esta pasta pode armazenar protótipos web, mobile ou de outros pontos de interação. Escolha telas e fluxos importantes para validar a solução; não é necessário prototipar toda tela por padrão.

## Alinhamento com o Trabalho de Graduação (TG — Fatec ADS)

Consulte o template institucional disponível em `docs/` e a orientação da disciplina sobre a inclusão de protótipos no documento acadêmico. Em projetos com interface móvel, indique plataforma, dimensões ou dispositivo de referência e interações próprias do toque quando forem relevantes.

## Diretrizes de Apresentação

- Cada protótipo selecionado pode ser acompanhado de uma **ficha descritiva** (ver modelo em [`ficha-prototipo-tela-template.md`](ficha-prototipo-tela-template.md)).
- O texto explicativo deve descrever os elementos e interações relevantes ao fluxo, como navegação, formulário, gesto ou botão de ação.
- Na monografia, inclua a imagem com o título na parte superior (tamanho 10) e a fonte no rodapé (`Fonte: Autor`, tamanho 10).

**Exemplo fictício:** um protótipo de consulta mostra a mesma tarefa no navegador e em uma tela Android. A versão mobile usa navegação por toque; a ficha identifica a plataforma e anota diferenças que afetam o fluxo.
