# Arquitetura e classes UML (quando aplicáveis)

Use esta pasta para explicar a arquitetura e as estruturas de classes quando isso ajudar a entender o projeto. Uma solução pode ter clientes web e móveis, API, processamento de dados, serviços externos ou apenas parte desses componentes. O diagrama deve mostrar o que existe no projeto e identificar itens planejados ou externos.

## Alinhamento com o Trabalho de Graduação (TG — Fatec ADS)

Consulte o template institucional disponível na pasta `docs/` e a orientação da disciplina para decidir como incluir figuras e sua explicação no documento acadêmico. Não exija diagrama de classes para uma solução sem estrutura orientada a objetos relevante.

## Conteúdo desta Pasta

- **[`diagrama-classes-template.md`](diagrama-classes-template.md):** Modelo de Diagrama de Classes UML com atributos, métodos, multiplicidades e associações estruturais.
- **[`visao-arquitetural-template.md`](visao-arquitetural-template.md):** Exemplo ajustável com clientes web/mobile, serviços, dados e integrações opcionais.

**Exemplo fictício:** um aplicativo móvel e um painel web compartilham uma API e um banco. A equipe marca os dois clientes, a API e o banco como implementados ou planejados na versão descrita; serviços que não existem ficam fora do desenho.
