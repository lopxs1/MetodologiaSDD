# Artefato — Modelagem de Dados e DER

Use esta pasta quando o projeto persistir, importar ou transformar dados estruturados. Para fontes públicas, analytics, armazenamento documental ou banco não relacional, registre o modelo e a proveniência que realmente expliquem a solução; o DER relacional pode não se aplicar.

## Alinhamento com o Trabalho de Graduação (TG — Fatec ADS)

Consulte o template institucional e a orientação da disciplina sobre quais modelos apresentar no documento acadêmico. Não crie um DER se não houver modelo relacional pertinente.

## Conteúdo desta Pasta

- **[`der-template.md`](der-template.md):** Modelo de apresentação do DER conceitual e lógico (com diagrama Mermaid e diretrizes de exportação).
- **[`dicionario-de-dados-template.md`](dicionario-de-dados-template.md):** Tabela estruturada com o detalhamento de entidades, campos, tipos, restrições e relacionamentos.

**Exemplo fictício:** um sistema de empréstimos mantém as entidades `Equipamento` e `Emprestimo`; um pipeline de dados, em vez disso, pode documentar fonte, período, colunas e transformações sem inventar entidades relacionais.
