# Diretório `mobile/` — Fora de Escopo (AMDE Digital)

Este diretório pertence à estrutura original do template do Projeto Integrador e encontra-se **fora de escopo** nesta entrega do projeto **AMDE Digital**.

## Justificativa de Escopo

- Conforme definido em [`.specify/memory/constitution.md`](../.specify/memory/constitution.md) e nas especificações `SPEC-001` a `SPEC-006`, a plataforma **AMDE Digital** é entregue exclusivamente como:
  - **API REST (`backend/`):** Java 17 LTS, Spring Boot 3, Spring Security 6, Spring Data JPA/Hibernate 6, Liquibase e PostgreSQL 18.
  - **Aplicação Web Responsiva (`frontend/`):** React 18, TypeScript, Vite e Tailwind CSS com adaptação responsiva (desktop e dispositivos móveis) via breakpoints Tailwind.
- **Estado:** Não aplicável / fora de escopo (nenhum aplicativo móvel nativo ou híbrido faz parte deste projeto).
